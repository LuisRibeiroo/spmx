`spmx` is a macOS command-line tool that keeps one global store of Swift Package Manager checkouts, bare Git repositories, binary artifacts, and macro prebuilts at `~/.spmx/store`, and clones them into every project and Git worktree on your Mac with APFS copy-on-write.

<StoreDiagram />

## Why it exists

Every Xcode and SwiftPM project creates its own isolated `DerivedData/<App>-<Hash>/SourcePackages` folder. Working across multiple apps, client repositories, branches, or Git worktrees means downloading and storing the same multi-gigabyte SDKs (`Firebase`, `Stripe`, `gRPC`, `SwiftSyntax`) in every project folder.

`spmx` works like Puro for Flutter or pnpm for Node.js. Each `(package, version)` slice is stored once in `~/.spmx/store` and cloned via `clonefile()` into any project that needs it, without changing your `Package.resolved` versions. Clones share disk blocks until a file is modified.

It works anywhere Swift Package Manager is invoked through `swift`, `xcodebuild`, or `flutter`, including native Xcode and Swift apps, Flutter, React Native, Expo, Capacitor, and Kotlin Multiplatform (KMP) projects on macOS.
