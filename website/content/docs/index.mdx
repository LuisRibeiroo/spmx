`spmx` is a macOS command-line tool that keeps one global store of Swift Package Manager checkouts, binary artifacts and macro prebuilts, and clones it into each Git worktree with APFS copy-on-write.

<StoreDiagram />

## Why it exists

Xcode derives the `DerivedData` folder name from a hash of the workspace path, so every new worktree starts with an empty `SourcePackages`. Each one downloads its own copy of the same dependencies.

spmx removes that cost. A package is downloaded once, stored under `~/.spmx/store`, and cloned into any worktree that needs it. Clones share disk blocks until a file is modified.
