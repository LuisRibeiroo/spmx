---
title: spmx status
description: Inspect project link state, package semantic versions, cache hit/miss status, and disk saved.
---

Shows how `spmx` sees a project: whether it is linked to the global store or unlinked, the active toolchain fingerprint, resolved `DerivedData` and `SourcePackages` paths, each package's semantic version and cache state (`hydrated / CoW clone`, `in store`, or `missing`), the estimated disk saved in this project, and LLVM CAS compilation cache status.

## Usage

```bash
spmx status [path] [flags]
```

## Flags

| Flag | Default | Description |
| :--- | :--- | :--- |
| `[path]` | `.` | Project directory, `.xcworkspace`, `.xcodeproj`, or `Package.swift`. |
| `--project <path>` | none | Explicit `.xcodeproj` or `Package.swift` path. |
| `--workspace <path>` | none | Explicit `.xcworkspace` path (cannot be combined with `--project`). |
| `--json` | `false` | Output machine-readable JSON including `isLinked`, `pinStatuses`, and `projectSavedBytes`. |
