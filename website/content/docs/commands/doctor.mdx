---
title: spmx doctor
description: Diagnose APFS, the Xcode and Swift toolchain, PATH shims, store integrity and Git hooks.
---

```bash
spmx doctor
```

Runs a series of checks and prints PASS, WARN or FAIL for each:

- the store volume is APFS, so clones are zero-copy
- Xcode and `xcodebuild` are present
- the active Swift supports the LLVM CAS compilation cache
- `~/.spmx/shims` comes before `flutter`, `xcodebuild` and `swift` in `PATH`
- the store, `index.json` and the compilation cache are valid and writable
- puro or fvm are compatible with the shims
- the state of Git hooks

```text
$ spmx doctor
spmx doctor
  [✓ PASS] APFS Filesystem: Store volume uses APFS; zero-copy clonefile() CoW is enabled.
  [✓ PASS] Xcode / xcodebuild: Detected Xcode 27.2 / Build version 27B52.
  [✓ PASS] PATH Shims Ordering: ~/.spmx/shims precedes flutter, xcodebuild, and swift in PATH.
  ...
Summary: 7 passed, 0 warning(s), 0 failure(s).
```

If a check fails, see [Troubleshooting](/docs/troubleshooting).
