---
title: spmx uninstall
description: Remove spmx shims, the binary and the shell profile PATH configuration.
---

```bash
spmx uninstall [--purge] [--yes]
```

| Option | Description |
| :--- | :--- |
| `--purge` | also delete `~/.spmx/store` and `~/.spmx/compilation-cache` |
| `-y`, `--yes` | skip the confirmation prompt |

Without `--yes` it asks first, and says explicitly when `--purge` will delete cached packages.

See [Uninstall](/docs/getting-started/uninstall) for the full picture.
