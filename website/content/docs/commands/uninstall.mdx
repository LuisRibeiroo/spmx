---
title: pspm uninstall
description: Remove pspm shims, the binary and the shell profile PATH configuration.
---

```bash
pspm uninstall [--purge] [--yes]
```

| Option | Description |
| :--- | :--- |
| `--purge` | also delete `~/.pspm/store` and `~/.pspm/compilation-cache` |
| `-y`, `--yes` | skip the confirmation prompt |

Without `--yes` it asks first, and says explicitly when `--purge` will delete cached packages.

See [Uninstall](/docs/getting-started/uninstall) for the full picture.
