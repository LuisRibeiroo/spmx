title: spmx store
description: Inspect cached package versions, per-project and global savings, and prune unreferenced store entries.
---

Manage `~/.spmx/store` and `~/.spmx/compilation-cache`.

## Subcommands

### `spmx store path`

Prints the resolved store directory path (`~/.spmx/store` or `SPMX_STORE_DIR`).

### `spmx store list`

Lists every cached `(package, version)` slice in `~/.spmx/store` with its semantic version, Git revision, size, and the linked projects that pull from it. Pass `--json` for machine-readable output.

```bash
spmx store list
spmx store list --json
```

### `spmx store status`

Reports checkout, bare repository, artifact, and toolchain-grouped prebuilt counts, compilation cache size, a per-project breakdown of saved disk space, and the total estimated disk saved across your Mac. Pass `--json` for machine-readable output.

```bash
spmx store status
spmx store status --json
```

### `spmx store prune` (`spmx prune`)

Removes missing project registrations, unreferenced store entries, and old compilation cache files, or configures opt-in automatic prune reminders via `spmx prune auto <enable|disable|status>`. Also available directly as [`spmx prune`](/docs/commands/prune).

| Flag | Default | Description |
| :--- | :--- | :--- |
| `--dry-run` | `false` | Preview removals and reclaimable bytes without deleting anything. |
| `--older-than <days>` | `30` | Only prune unreferenced entries and cache files older than this many days (`0` prunes all unreferenced). |
| `--auto-every <days>` | `30` | Configure the automatic prune reminder interval in days (`0` disables). |
| `--enable-auto` | `false` | Enable automatic prune reminders on explicit `spmx` commands. |
| `--disable-auto` | `false` | Disable automatic prune reminders. |
| `--status` | `false` | Show the current automatic prune configuration and last prune timestamp. |
| `--json` | `false` | Output machine-readable JSON. |
