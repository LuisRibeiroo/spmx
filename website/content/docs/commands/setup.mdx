---
title: spmx setup
description: Create ~/.spmx, link the shims and add them to your shell profile.
---

```bash
spmx setup [--no-modify-path]
```

Creates the `~/.spmx` directories, symlinks `flutter`, `xcodebuild` and `swift` into `~/.spmx/shims`, and adds the shims and binary directories to your `PATH` in the detected shell profile (`~/.zshrc`, `~/.bashrc` or `~/.config/fish/config.fish`). It is idempotent: running it again changes nothing.

## Options

| Option | Description |
| :--- | :--- |
| `--no-modify-path` | do not edit any shell profile file |

## Examples

```bash
spmx setup
spmx setup --no-modify-path   # then export PATH yourself
```
