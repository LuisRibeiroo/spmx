---
title: Quick start
description: Set up the global SwiftPM store and link projects across your Mac in under two minutes.
---

```bash
# 1. One-time setup: directories, shims, PATH
spmx setup

# 2. Check that APFS, Xcode, PATH order and the store are healthy
spmx doctor

# 3. Link existing projects on your Mac (shows plan & GB saved, asks to confirm)
spmx link

# Or target a specific folder
spmx link ~/projects/client-x

# 4. Build as usual. The shim hydrates SourcePackages first and harvests new versions after
flutter run                    # Flutter + SwiftPM
xcodebuild -scheme App build   # native Xcode
swift build                    # SwiftPM CLI

# Inspect link state, semantic versions, and disk saved in this project
spmx status

# List every (package, version) in ~/.spmx/store and which projects use it
spmx store list

# See per-project breakdown and total GB saved across your Mac
spmx store status

# Isolate a specific project to use only its local Xcode/SwiftPM cache
spmx unlink ~/projects/legacy-app

# Bypass spmx for a single command
SPMX_DISABLE=1 flutter run
```
