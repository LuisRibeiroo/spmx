---
title: Installation
description: Install spmx with Homebrew or a one-line script, then run setup.
---

spmx runs on macOS, on Apple Silicon and Intel. It is a single universal binary with no runtime dependencies.

<Tabs items={["Homebrew", "curl"]}>
  <Tab value="Homebrew">
    ```bash
    brew install LuisRibeiroo/tap/spmx
    spmx setup
    ```
  </Tab>
  <Tab value="curl">
    ```bash
    curl -fsSL https://raw.githubusercontent.com/LuisRibeiroo/spmx/main/scripts/install.sh | sh
    ```
    The script detects your architecture, downloads the release archive, verifies its SHA-256 checksum, installs the binary to `~/.spmx/bin/spmx` and runs `spmx setup` for you.
  </Tab>
</Tabs>

<Callout type="warn" title="Homebrew tap">
  The formula template lives in the repository at `Formula/spmx.rb`. The tap and the first release are not published yet, so use the curl installer until they are.
</Callout>

## What `spmx setup` does

1. Creates `~/.spmx` with `store`, `compilation-cache`, `bin` and `shims` directories.
2. Links `flutter`, `xcodebuild` and `swift` in `~/.spmx/shims` to the spmx binary.
3. Adds `~/.spmx/shims` and `~/.spmx/bin` to your `PATH` in `~/.zshrc`, `~/.bashrc` or `~/.config/fish/config.fish`, once and idempotently.

Pass `--no-modify-path` to skip step 3 and add the line yourself:

```bash
export PATH="$HOME/.spmx/shims:$HOME/.spmx/bin:$PATH"
```

Open a new shell, then confirm everything is in order:

```bash
spmx doctor
```

<Callout type="info">
  Git hooks stay **off** after installation. See [`spmx hooks`](/docs/commands/hooks) to opt in.
</Callout>
