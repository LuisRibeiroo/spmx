---
title: Uninstall
description: Remove spmx, its shims and its PATH entries, with or without the cached packages.
---

```bash
spmx uninstall
```

This removes the shims, the spmx binary and the PATH lines that `spmx setup` added to your shell profile. It asks for confirmation first; pass `--yes` to skip the prompt.

To also delete cached packages and the compilation cache:

```bash
spmx uninstall --purge
```

`--purge` removes `~/.spmx/store` and `~/.spmx/compilation-cache`. Your worktrees are not touched: their `SourcePackages` are real files, not links into the store, so they keep working.

<Callout type="info">
  If you enabled Git hooks, run `spmx hooks disable --global` (and `--repo` in any repository where you enabled them) before uninstalling.
</Callout>

See the [`uninstall` reference](/docs/commands/uninstall).
