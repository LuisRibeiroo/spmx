## From the terminal

With the shims on your `PATH`, nothing changes:

```bash
xcodebuild -workspace App.xcworkspace -scheme App build
swift build
swift test
```

The `xcodebuild` shim hydrates `DerivedData/.../SourcePackages` before running Xcode's tool and harvests afterwards. If you pass `-clonedSourcePackagesDirPath` yourself, pspm treats that as an explicit choice and does not hydrate.

On Xcode 16+ and Swift 6+ it also enables the [shared compilation cache](/docs/concepts/llvm-compilation-cache) unless you set `PSPM_NO_COMPILE_CACHE=1` or pass your own cache flags.

## From the Xcode app

Xcode does not read your shell `PATH`, so shims cannot intercept a project opened from Finder or the Dock. Pre-warm instead:

```bash
pspm hooks enable --global
```

Now `git worktree add` hydrates the new worktree before you open it. See [`pspm hooks`](/docs/commands/hooks).

## Checking one project

```bash
pspm status                  # type, toolchain, paths, cached pins
pspm derived-data-path App.xcworkspace
```
